1 · A coding agent at work

DSH runs headless and talks to the Token Factory public endpoint. It reads code, edits it and runs the tests. Afterwards the harness judges the result with hidden tests the agent never saw.

The task given to the agent


        
Run it live

        
python3 harness/run_task.py t3 --live

        
A live run takes about 10–30 s and costs under $0.01. Rebuild with npm run build to add it here. The recorded runs below are the fallback if the network is down.

    4 · Pay per token or pay per GPU-hour?
    
      
    Public endpoint: measured tokens per task × verified prices. Dedicated endpoint: GPU-hours × an assumed price. The number of GPUs is sized from benchmark throughput, so bigger volume means more GPUs, not one GPU that absorbs everything.

    5 · A classroom of agents
    
      
    Every simulated student runs real recorded DSH trajectories: the same sequence of LLM requests, token counts and tool gaps that we measured. The simulation then asks whether each backend keeps up, and at what cost.
